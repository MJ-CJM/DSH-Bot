# DSH-Bot

[English](README.en.md) · 中文

**你的个人智能体工作区。** 在 DeepSeek Harness 中创建各有职责、记忆与工具的 Bot，持续对话、分工协作，并在原对话中拿到结果。

**当前源码：0.7.0 待发布候选（npm 包名 `dsh-botgroup`）。** 本页介绍候选中的 Bot 模式、Supergroup 和简化工作流程；不表示已经公开发布。[公开稳定版 0.6.7](https://github.com/MJ-CJM/DSH-Bot/releases/tag/v0.6.7) 的内容与安装包以该 Release 为准。[更新记录](https://github.com/MJ-CJM/DSH-Bot/blob/main/CHANGELOG.md)。

## 从一个 Bot 开始

安装到**具有对应宿主适配的环境**后，日常使用无需先建项目或手动组队：

1. 在左下模式菜单选择 **Bot 模式**，选择或新建一个 Bot，直接描述任务。例如：“比较这两份方案，需要时请研究员和审阅助手一起检查。”
2. Bot 可围绕当前任务互问、委派或自动组队，需要时邀请已有专家。你可以查看协作过程，结果仍由发起 Bot 在**原对话**交付。
3. 要补充文件，打开右上 **资料与详情 → 资料**，选择本次任务要用的文本文件，再继续原任务。需要调整要求或停止时，在原工作上操作。
4. 左下 **工作与管理** 打开 Bot／群目录及需要本人处理的事项；无需切回标准模式找功能。

Bot 模式会开启任务内自动协作；切回标准模式会停止协作并保留记录，模式选择对所有窗口生效。文件权限、工具审批与模型配置沿用宿主。聊天需要 DSH 中可用的模型，模型服务可能产生费用。

## 常用功能在哪里

| 想做什么 | 入口与行为 |
| --- | --- |
| 看任务和主动跟进 | Bot 或群对话 → 资料与详情 → 任务。跟进需要为该 Bot／群明确开启。 |
| 补充资料并继续 | 资料与详情 → 资料。选择准确任务和文本文件，原问题默认保留；附加要求可选填。 |
| 看待处理事项 | 工作与管理 → 需要本人处理的任务。回到原对话补充信息、核对结果或使用原生提问／审批入口。 |
| 管理职责与记忆 | Bot 的资料与详情 → 详情，进入完整设置或管理已保存的记忆。 |
| 调整群与复用团队 | 群的资料与详情 → 设置，查看群偏好及团队配方。 |
| 配置可选服务 | 工作与管理中的高级设置；日常任务继续在 Bot／群对话中处理。 |

### 自动协作，结果回到原对话

Supergroup 复用 DSH 原生子任务、模型、工具和审批能力。已有 Bot 可根据任务自动组队，并在协作中请求其他已有专家支持；不必预先选齐成员。群里可查看真实成员、过程、用量与公开成果，也可补充任务或停止协作。

共享范围是当前任务文字、明确选择的资料及已授权成果。私人聊天与私有记忆不会自动整份交给队友；工作目录也不构成文件沙箱。具体回答和分工取决于模型、工具、权限和任务资料。

### 缺少资料或连接时，继续同一项工作

资料页显示当前原任务与获准读者，可直接选择有限文本文件；连接问题出现时，从原工作进入连接与凭据设置。**连接就绪后仍需明确继续原任务**，不会因为配置完成而自动重放。

工作目录汇总待补充、待核对、结果未知及可用的原生提问／审批入口。打开或阅读不会解决事项；审批仍在原生控件处理。交付或执行结果未知时，先核对已有操作，不自动重新执行。

### 可选的非定时跟进

在 **资料与详情 → 任务 → 开启主动跟进** 为当前 Bot 或群开启。本地查看与刷新不调用模型，不需要 GitHub 账号或外部凭据；跟进与实际执行分别授权。

已有支持的任务卡提供 **关注此任务**，自动填入任务名称、可用条件和可修改的截止时间。你可以观察原生子任务完成，或已配置来源的下一个 GitHub CI 结果；也可手工登记事项和完成条件。**保存前可以修改或取消，打开表单不会建立关注。** 条件满足后进入待核对，不自动启动模型或重做任务。

个人 Bot 聊天中的登记沿用原生工具审批；群聊提案需要明确“确认关注”才生效。可停止单项或暂停该 Bot／群的观察。此功能**不是定时提醒**，依赖本地 DSH Host 运行；普通日程继续使用 DSH 原生能力。

### 记忆有来源，也能核对变更

每个 Bot 有独立记忆。在记忆页查看 **最近记忆变更** 的来源、时间和前后差异；对允许恢复的历史版本，可明确选择 **恢复为新修订**。已遗忘、已撤销或当前无权读取的内容不会因此复活。

开启 Bot 记忆后，可在 **记忆 → 参与的群工作** 搜索本人实际参与且仍可访问的群记录，并打开原文。在群成员菜单选择“在单聊中追问”会准备带引用的草稿，发送仍由你决定。查到群记录不会自动存成长期记忆，私有记忆也不会自动共享。

### 保存团队偏好，按需使用普通群

群设置中的 **团队配方** 自动预览当前团队，可以直接保存；导入与 JSON 编辑收在高级入口，导出按钮保留在预览区。应用前预览角色映射，并明确确认成员变化。配方只含团队偏好，不含聊天、记忆、凭据或执行授权；**新加入成员可以查看该群共享历史**。

手动创建的普通群默认按问题在本地选择相关发言者，可在设置中关闭。明确 @、回复和轮次优先；无匹配时沿用原路由，选择过程不调用决策模型，成员回答仍会调用模型。已有群保留原偏好。Supergroup 自动团队围绕任务协作，无需配置普通群的发言方式。

![普通群协作与成员执行过程示例](https://raw.githubusercontent.com/MJ-CJM/DSH-Bot/main/packages/dsh-bot/assets/showcase/zh-group.png)

原生后台任务、结果验收、普通日程、Bot 消息以及可选的文档快照分析与工作方法评估仍保留在任务／管理入口。高级执行和外部连接按需配置，不是开始 Bot 对话的前置步骤。

## 安装与兼容性

| 范围 | 当前说明 |
| --- | --- |
| 公开稳定版 | [0.6.7 Release](https://github.com/MJ-CJM/DSH-Bot/releases/tag/v0.6.7)，不要把本页候选功能当作稳定包已经包含的功能。 |
| 当前候选 | 0.7.0，尚未公开发布；产品包为 `dsh-botgroup-0.7.0.tgz`，使用本轮准备并校验的候选包及配套兼容产物。 |
| 完整 Bot 模式 | 需要命令路由、聊天动作和空白会话预设适配。已验证的官方桌面组合为 **macOS arm64 DSH 0.2.2-rc.3 + 对应的独立 dsh-bot-web-app 适配包 + DSH-Bot**。 |
| 其他宿主 | 声明范围为 `>=0.2.1-rc.2 <0.3.0`，开发依赖锁定 `0.2.1-rc.2`。范围不代表所有版本或平台实测；原版宿主缺少能力时会拒绝开启完整 Bot 模式。 |

**只安装 DSH-Bot tgz 不会自动补齐宿主适配。** 当前没有跨版本自动 fallback；升级 DSH 前需同步核对并迁移兼容组合。兼容产物与宿主精确版本绑定，不能把 rc.3 组合直接用于其他版本，也不需要修改官方应用签名。

### 已发布版本

公开 npm 包名为 **[dsh-botgroup](https://www.npmjs.com/package/dsh-botgroup)**；产品品牌、插件 ID 与数据目录仍为 DSH-Bot／`dsh-bot`。稳定版版本包为 `dsh-botgroup-0.6.7.tgz`，固定下载名 `dsh-bot.tgz` 是同包别名。

打开对应 [Release](https://github.com/MJ-CJM/DSH-Bot/releases)，阅读它自己的兼容说明，下载插件 tgz 和同一 Release 的校验文件。macOS 校验示例：

```sh
shasum -a 256 -c dsh-bot.tgz.sha256
```

在 DSH 中通过 **插件 → 添加插件 → 安装第三方插件** 选择 tgz，按宿主提示启用并完全退出重开。源码压缩包不是预构建插件。社区市场或 `latest` 地址可能仍指向稳定版，不能据此获取未发布候选或证明 Bot 模式兼容。

### 当前候选

候选应由维护者按[候选交付说明](https://github.com/MJ-CJM/DSH-Bot/blob/main/docs/releases/v0.7.0.md)准备、校验并安装到对应兼容环境；不要从稳定版下载地址推断候选已上线。完整 Bot 模式的验证与部署必须同时核对产品包、适配包和宿主版本。

从旧 `dsh-bot` 包迁移时，先停止 Host 并备份完整 profile 和数据，通过原生插件管理移除旧包，再安装 `dsh-botgroup`。启动前检查 profile 的 `cordis.patch.yml`：原 `id: dsh-bot` 覆盖行若带 `name: dsh-bot`，仅改成 `name: dsh-botgroup`，保留 id、config 与 dataDir；没有 name 的行无需新增。不要同时保留两个包依赖或 bundle；自定义包含层／模板中的旧包引用需另行核对。[迁移说明](https://github.com/MJ-CJM/DSH-Bot/releases/tag/v0.6.7)。

升级前备份原 profile 和完整数据，保留原存储位置；不要通过删除 Bot 或重置数据升级。数据迁移后回退需要升级前备份。外部连接、付费执行和共享权限不会因升级自动获得授权。

## 验证与边界

候选功能已有真实 Host、持久化和浏览器验证，包括亮色中文、暗色英文、窄屏、原对话交付与数据保留；模型使用确定性本地模拟。原先标为 0.6.6 的本地开发包是这些历史验收的输入，**不是本次 0.7.0 发布包的验证收据**。本次候选的精确包与检查结果见[候选交付说明](https://github.com/MJ-CJM/DSH-Bot/blob/main/docs/releases/v0.7.0.md)；功能路径与历史证据见[低配置体验](https://github.com/MJ-CJM/DSH-Bot/blob/main/docs/verification/simple-bot-workflow.md)、[增量验收](https://github.com/MJ-CJM/DSH-Bot/blob/main/docs/verification/openmaus-improvements.md)和[宿主组合验证](https://github.com/MJ-CJM/DSH-Bot/blob/main/docs/verification/official-signed-desktop-update.md)。

真实付费模型的专业质量、外部账号认证、外部 IM 收发及未来宿主自动适配未由这些检查证明。任务依赖本地 Host 运行；当前不提供云端常驻、系统退出后的持续执行或系统／手机推送。不确定的执行结果不会自动重放。
