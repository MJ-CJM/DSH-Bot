# 0.7.0 发布候选准备

日期：2026-11-16（America/Los_Angeles）。**本地候选已冻结，尚未发布**。本版安装包名为 `dsh-botgroup`，保留 DSH-Bot 品牌、内部 `dsh-bot` 插件 ID、Bot／群身份和原数据目录。当前公开稳定版为 [v0.6.7](https://github.com/MJ-CJM/DSH-Bot/releases/tag/v0.6.7)。不覆盖历史版本或附件。

## 本版功能

- Bot 模式以联系人和群聊为入口，保留 DSH 原生聊天、附件、审批与模式切换；工作与管理入口直接返回目录，任务／资料／群设置在对话详情内可用。
- Supergroup 自动组队、协作中邀请已有专家，在原对话返回结果并继续任务。既有消息模式和双方可见消息记录保留。
- 在原任务中补充明确资料并续办，待处理事项保留真实来源、状态和审批入口。
- 条件跟进可从已有任务一键预填，主动跟进仍需本人开启；群路由可选按需响应，新群默认使用此偏好，旧群保留原设置。
- 团队配方默认预览当前成员，导入与高级编辑折叠；记忆变更可查看与恢复，沿用既有共享／遗忘边界。

## 安装与兼容

- 标准插件包为 `dsh-botgroup-0.7.0.tgz`，固定名称 `dsh-bot.tgz` 必须是相同字节。候选尚不在 npm／GitHub Release 提供下载。
- 依赖参考仍锁定 DSH `0.2.1-rc.2`；manifest 的 `>=0.2.1-rc.2 <0.3.0` 范围不是全版本测试承诺。
- 完整 Bot 模式需要宿主命令／工作区／聊天能力。官方 `0.2.2-rc.3` 使用经核对的独立 `dsh-bot-web-app` 适配包；普通产品 tgz 不包含这三个原生 Client 适配。适配层只通过 profile 组合加载，官方应用和签名不修改。
- 适配包仅适用于记录的精确官方版本及 ASAR SHA。不得同时选择官方 web-app 和替代 web-app。宿主升级时需重新核对适配，不能承诺自动回退或任意新版可用。
- 既有 `dsh-botgroup@0.6.7` 用户在同一 profile 原位升级。旧 `dsh-bot` 用户先正常停止 Host 并完整备份，再移除旧包、安装新包；具名覆盖行中只将 `name: dsh-bot` 改为 `name: dsh-botgroup`，保留 `id: dsh-bot`、config、dataDir。不要同时安装两份产品包。
- 详细常规流程见[中文说明](../../README.md)、[英文说明](../../README.en.md)与[社区发布流程](../community-release.md)。本轮不改日常桌面或用户数据。
