# v0.6.4 / Group statistics, commands and Bot messages

状态：候选验收中。本页在发布前填写同一安装包的实际结果；未运行项保留为 FAIL（NOT_RUN）。

## 功能与变更

相对 [v0.6.3](v0.6.3.md)：

- 群聊统计：每个问题下的成员 token、缓存命中与活动，历史问题选择（[#24](https://github.com/MJ-CJM/DSH-Bot/pull/24)）；原生输入区样式的统计栏、带状态与当前选择的问题菜单、“整个群聊”合计（[#31](https://github.com/MJ-CJM/DSH-Bot/pull/31)）。
- Bot 间消息在双方对话中可见，Bot 详情可在会话右侧打开（#31）。
- 群输入框 `/` 命令菜单与 `+` 按钮，按宿主为群会话提供的命令目录显示（#31）。
- 群访问模式在运行或排队时可切换，建群时选择工作区，并提示越权拒绝（[#27](https://github.com/MJ-CJM/DSH-Bot/pull/27)）。
- 成员运行失败时显示原生原因（[#29](https://github.com/MJ-CJM/DSH-Bot/pull/29)）。

各项的设计与验证见 [群聊统计](../verification/group-statistics/README.md)、[群访问模式](../verification/group-permissions.md)、[Bot 消息、群命令与统计栏](../verification/bot-message-presence.md)、[成员失败原因](../verification/group-failure-reason.md)。

## 兼容与升级

- 宿主声明范围仍为 `>=0.2.1-rc.2 <0.3.0`，peer 与依赖不变，无新增依赖。
- 存储：只在群成员投递记录上新增可选的 `failure` 字段，旧记录不迁移、照常读取。
- **不能直接降级到 0.6.3。** 0.6.3 打开群数据时按严格 schema 逐条校验（`@deepseek-ai/dsh-storage-domain` 未设 `invalidRecords` 时任何一条不合格即拒绝打开），不接受 `failure` 字段；一旦记录过成员失败原因，0.6.3 的群数据无法打开，插件启动失败。回退须恢复升级前的完整备份。该结论来自 0.6.3 源码与锁定 rc.2 包的只读核对。
