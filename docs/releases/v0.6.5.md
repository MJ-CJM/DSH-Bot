## 已知限制与验收范围

1. 打开 Bot 详情应显示紧凑的原生弹窗，不缩窄聊天区；“完整设置”应进入同一 Bot，并可返回。
2. 验证群目录刷新、成员/活动/设置、历史问题统计，以及关闭修改过的群编辑表单时的保留/丢弃确认。
3. 当前宿主 `0.2.2-rc.1` 的 Schedule 数据结构兼容问题仍见 [Bot 预览验收](../verification/bot-preview-layout.md)，本次未修复或验证定时任务执行。
4. PR #25 的六项直接准入测试不能证明完整启动故障已隔离。只读源码显示：存储/记忆初始化失败的清理先调用 `MemoryAdmission.close()`，将 `stopped` 设为 true，外层再标记永久启动失败；新放行分支要求 `!stopped`。该路径的普通会话仍可能被阻断。另有空归属查询被当作已知的边界，尚需真实 Host 验证。本次保留合入实现并明确记录，不把源码审查或单元测试当作故障运行验收。

安装前备份原 profile；升级后完全退出并重开 DSH，避免旧进程模块缓存影响验证。本次发布不自动升级用户已安装的插件。
