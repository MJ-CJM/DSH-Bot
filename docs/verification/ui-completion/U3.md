# U3 — 群聊阅读与成员操作

- 每个问题下的执行入口默认收起；用户选择按原群身份/turn 保存，刷新与重挂载不会展开其他问题。
- 查看原生执行详情是明确的主操作；补充与停止成员进入公开 Menu，整轮停止仍单独显示。自动后续执行次数进入折叠诊断，不改额度和继续协议。
- 窄屏群资料为单列，返回恢复列表触发位置；成员编辑返回增加草稿确认。
- 保留原生 reasoning factory 和只读 child 会话。公开 factory 没有安全过滤内部派发 prompt 的参数；不修改原生日志或依赖私有组件。
