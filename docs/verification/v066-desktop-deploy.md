## 冷备份与安装

通过原生应用菜单正常退出，确认应用进程和数据目录文件句柄均已关闭后，备份整个 DSH 数据目录。协调库位于 profile 外部，因此没有仅备份 desktop profile。

- 私有证据目录权限为 0700，完整归档权限为 0600。归档包含私人数据，仅留本地。
- 备份前后的 2,855 个非依赖文件摘要一致。安装前后，原有文件仅 `profiles/desktop/package.json` 和 `profiles/desktop/pnpm-lock.yaml` 改变，其余 2,853 个文件摘要不变，无缺失。

从仓库根执行：

```sh
DSH_HOME="$HOME/.dsh" \
DSH_BOT_DSH_BIN='/Applications/DeepSeek Harness.app/Contents/Resources/runtime/cli/bin/dsh' \
scripts/dsh plugin --profile desktop add "$PWD/dist/release-candidates/v0.6.6-2151c9ab120b/dsh-bot-0.6.6.tgz"
```

退出码 0，DSH-Bot 从 0.6.5 升级为 0.6.6，未下载新依赖。已有弃用子依赖和 peer 提示未阻止安装。安装日志、备份收据、安装核验和数据保留记录均保留在本地私有证据目录。

## 改动与使用

- 日常环境：DSH-Bot 安装文件、desktop profile 的包清单与锁文件，以及原生启动日志、缓存和协调库 schema 迁移。
- 仓库：本部署报告、[0.6.6 交付记录](../releases/v0.6.6.md)、忽略目录中的备份、收据与候选部署状态。业务源码和安装包字节未变。
- 个人：Bot 详情 → 任务 → 开启主动跟进。
- 群：管理群聊 → 活动 → 开启主动跟进。
- 开关按个人和群分别控制。保留原配置，不代替用户开启新范围或主动执行。
- 0.6.6 交付非定时跟进；定时能力仍按用户决定延期。

需要回退时，先正常退出 DSH，并另外备份升级后新增数据，再恢复本次升级前的完整快照；不能让旧插件直接写入已迁移为 schema 9 的数据。
