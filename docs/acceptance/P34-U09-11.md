## 决策与遗留

1. 决策：internal 默认，graph 是 main-only 附加库。理由：参考服务器整文件覆写且无 CAS；唯一主 Agent、进程内 writer lease 与同一原生工具队列给出已测的单写者边界。单后端仍只支持一个 Host，外部写进程不在协调范围。
2. 决策：关闭原生自动 reconnect，故障后显式 apply。理由：先 await 旧 child quiescence，再重新取得 writer，避免代际进程重叠；损坏数据不自动清空。PTC 未支持的图谱组合一律停止写入。
3. 决策：技能传输只做 UTF-8 文本、128 文件/1 MiB，不自行增加压缩包系统。理由：SKILL.md 与文本引用可直接审阅，拒绝 binary/符号链接/越界/覆盖，不默默损坏文件。
4. 决策：导入/复制存独立可恢复清单，不删除原数据。理由：底层没有跨表/文件事务；部分新 Bot/批量导入失败标 failed 并保留已创建记录供核对，不能自动覆盖或声称原子回滚。预览和复制清单当前没有自动裁剪。
5. 图谱副本只包含内部条目；自然实体/关系保留在旧文件。启用后两处独立写入；active Agent prompt 不因复制重建，重新创建 Agent 才重新计算既有快照。
6. 建议编排方在允许 Chromium 启动的既定环境复跑同一 runtime 命令，补管理与图谱的中英/亮暗/窄屏截图。最终 0.3.0 tgz、全期交互与真实桌面/平台由 U12/U13 完成；本轮没有请求绕过沙箱或修改桌面安装。
