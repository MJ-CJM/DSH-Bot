## 设计取舍与限制

1. `activity.list()` 返回 `{sessions,bots}`；空 Bot 的聚合时间为 0、unreadCount 为 0，不制造空会话记录。rc.2 Gateway 强制参数数量，因此公开 list 为真正零参；可选 botId 过滤未作为 wire 参数，消费者可过滤返回值。`dsh-bot/remote` 导出活动类型及方法类型。
2. 活动与 Bot/Memory 共用 `dsh_bot` version 1 和同一写队列；兼容旧文件缺少活动表。只保留摘要，内部 `lastEventSeq` 不暴露给 Client。Host 自定义事件不转发，T08d 仍按轮询/重取接入。
3. 为处理同毫秒和时钟回退，消息/已读采用不回退的逻辑毫秒值；markRead 不修改 updatedAt。Registry 候选与持久 Bot 共享单调创建时间，旧 Agent 无法借同 id 重建恢复旧活动。
4. 标题仅在完成消息时从公开 projection 采样，单独重命名将在下一条消息后更新。历史 seed 不重放；不回填安装前或已淘汰的历史会话消息。纯图片用户消息记录空 preview；无可见文本的 assistant 工具/推理步骤不覆盖已有摘要。
5. secret 检测复用已有保守签名策略，存在误报/漏报可能；不会宣称完整凭据识别。后端没有跨表事务，淘汰/删除中途 I/O 失败可留下部分清理，Bot 保留以重试；不承诺多 Host 并发写同一 JSON 域。
6. 本次不验收 UI、浏览器主题或真实模型效果，它们不属于 T08c 要求。后续 T08d 可直接消费活动 Remote；没有尚未完成的本任务必验项。
