设计取舍与遗留边界：

1. 保持现有 CRUD 返回值，新增无参数 `status()` 返回实时视图。状态不落库，Client 不拼前缀；T08 同步刷新 list/status，避免旧响应覆盖新数据。状态只是瞬时观测，“开始聊天”仍需处理创建时 preset 已被删除的错误。
2. reconcile 只操作本实例持有 disposer 的注册，不按前缀清除其它插件。与其它插件同 id 冲突时仍报 unavailable，需处理冲突后重试。致命存储打开失败不走写前自愈，需修复存储/配置并重启；不会自动修改坏记录。已有 broken Bot 本身不触发全局 failed；只有补偿失败后才全局校准。
3. Host apply 已运行、Client contribution 已 mount 后，未就绪/致命失败返回 `bot/unavailable`。Client 未 mount 时 namespace 不存在；Host 未加载或依赖未满足且 descriptor 存在时，Gateway 可返回 `gateway/service-unavailable`（API notes 有源码依据）。T08 显示“Bot 服务尚未就绪或加载失败”，保留原因和刷新入口，不能把它当作空列表。
4. **删除 Bot 不删除历史会话，但移除其 preset。** 底层解析/新建为 `agent-preset/not-found`；T02 冷恢复实际是 `gateway/internal` + `Unknown agent preset: <id>`，由 SessionController 包装（`src/agent.ts:235-256`）。活跃 Agent 保留旧代际；同 id 重建后恢复使用当前定义，不保证历史快照。T08 删除提示：“删除后，依赖此 Bot 的历史会话将无法恢复；历史记录不会一并删除。”更新提示：“活跃会话继续使用原配置，新会话及重新恢复的会话使用当前配置。”
5. `status.preset.state === 'ok'` 才启用“开始聊天”；broken/missing 显示“此 Bot 暂不可用：{reason}”，提供编辑修复、删除、刷新。文案国际化和 UI 行为留 T08；真实组合、会话工具闭环与 Desktop 验收仍按原计划推进。当前无阻塞本轮五项修订的遗留问题。

## 设计取舍与遗留

1. **稳定 preset ID + 补偿事务**：符合 T02。注册健康后才落库；同 id 注销/重注册仍有短暂选择器空窗，不能称为跨 preset 与 storage 的原子事务。活跃会话保持旧代际；冷恢复取当前定义。
2. **Remote 删除别名**：rc.2 Client namespace 保留 `remove`，所以 wire 使用 `delete`，公开 descriptor 映射回同一个 Host `remove`。Client 必须显式传第二个参数（可以是 undefined），这是 Gateway 的严格实参数量规则。T08/T09 应直接使用本包派生类型，不能恢复旧任务中的 `remote.dshBot.remove` 示例。
3. **一次性示例标记**：新 `registry_state` 表兼容读取 T03 旧文件，pending 支持初始化中断恢复；不支持旧版写入器降级回写后继续保留新增表。
4. **仅 Host 事件**：不替换宿主全局事件源。Client 暂无页面数据 store；T08 按 refetch/reset/显示时刷新 + 低频轮询实现跨 Client 刷新。
5. **T05 占位边界**：standard/minimal 当前都只注入 persona。`dataDir` 已有默认与解析，不创建技能目录；模板、模型、技能、工具限制仍由 T05 负责。
6. **记忆边界**：duplicate 不复制记忆。删除默认清理；显式 `deleteMemories:false` 会保留原 id 记忆，同 id 重建可重新关联。T03 后端没有跨表事务，记忆清理途中失败可能部分删除，恢复 Bot/preset 后可重试，不能宣称全部记忆回滚。
7. **后续建议**：T05 继续验证真实组合健康和 agent 作用域；T08 使用 delete 别名、派生签名与 refetch 策略；T10 再做 Desktop/UI、冷恢复会话及 mock 模型工具闭环。
8. **Remote 清空字段**：`avatar/model/defaultCwd/order` 用 null 清空，Host 再规范化；Host 仍兼容显式 undefined，省略字段保持原值。直接 Client 调用不得依赖 undefined 清空，因为 HTTP JSON 会丢键；T08 编辑器应发送 null。必填字段 null 继续拒绝。
