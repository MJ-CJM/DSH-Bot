## 改动与决策

- 12 色：蓝、绿、琥珀、红、青绿、青蓝、靛蓝、紫、玫瑰、橙、橄榄、灰蓝；均有中英名称，仅由宿主 alias token 混合。
- 6 种造型：经典、戴眼镜、喷水、小鲸鱼、戴帽子、睡觉（闭眼 + Zz）。经典保留既有 DSH 轮廓；其余使用本次原创的共享身体路径与几何装饰，单色 currentColor/透明负空间，无外部素材。导航仍使用经典造型。
- 编辑器按造型、颜色分两行；fieldsets 有 accessible name，每项是原生按钮和 aria-pressed；支持 Tab/Enter/Space、左右循环/Home/End，禁用时不更改值。窄屏可换行，图片/emoji 的原有优先级与上传校验保持有效。
- 决策：新增可选 `avatarVariant`，用显式 `auto` 表示自动造型，缺省解析为旧记录、渲染为 classic。理由：自动模式不能与旧数据缺失字段混同。新建编辑器默认 auto，API 省略字段仍按兼容规则显示 classic；自动按钮同时清空指定颜色。未改 schemaVersion，未主动改写旧库。
- 决策：保留 `avatarColor` 的四个旧 ID，追加八个命名配色 ID。理由：可兼容既有数据，并通过受限枚举控制输入；无需新增配置、依赖或 Host 服务。造型/颜色分别按 Bot ID 的两个 FNV-1a 哈希域确定，显式颜色与造型可单独选择。
- 原生能力依据与取舍见 [API 记录](../dsh-api-notes.md#r06：12-色与-6-种鲸鱼头像2026-10-21) 和 [架构](../architecture.md#r06：头像造型与配色)。只读参考 tag 核实为 `dsh-v0.2.1-rc.2`。
