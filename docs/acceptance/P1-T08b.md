## 设计取舍

- `avatarColor` 使用受限主题 token 名，蓝/绿/琥珀/红。色值以 72% 颜色 token + 28% 主文字 token 混合，无任意 CSS/hex。fixture 与 T08 token fixture 同源 SHA256。非文本图形对比：亮色 6.59/3.96/4.71/7.24，暗色 9.94/9.77/8.68/7.51；最低高于 3:1。自定义主题未保证。
- `avatar` 保持单字段，图片与 emoji 互斥；色板明确切回鲸鱼。旧记录不改写，无 avatarColor 时由 id 哈希选色；schemaVersion 仍为 1。PNG/JPEG/GIF/WebP 上传沿用严格 64 KiB 编码限制，不声称完成图像解码验证。
- 工作区偏好只保留在当前 Client 插件内存，不跨连接持久化。多个工作区每次询问、预选上次成功项；在公开 beforeOpen 通过生命周期 guard 后记忆，避免成功导航卸载页面后丢失偏好，不记忆被覆盖的导航。
- 使用公开 footer action 弹层，原 Bots 管理入口保留；未替换 single 或拼接私有 React 实现。会话“更多”按配置数增加已加载共享列表的显示量，不伪造远端分页。Bot 会话仍可出现在原工作区列表。
- 侧栏/徽标 catalog 被动订阅，无常驻轮询；仅管理页持有轮询 lease。其他 Client 修改 Bot 的可见性沿用重显、重连、手动刷新或页面轮询，不保证立即推送。
- rc.2 npm primitives 直接 Node import 缺 `clsx`（上游仅声明 devDependency）。单测采用显式平台 atom doubles；正式包 runtime 只从平台 require 取真实原语。未修补 node_modules，单测不能证明真实 Menu 放置、SVG path 或 CSS 视觉。

```sh
scripts/pnpm install --frozen-lockfile
scripts/pnpm check
DSH_HOME="$PWD/.dsh-shot" node scripts/screenshot.mjs
```

脚本固定 `.dsh-shot`，复用已有 `~/Library/Caches/ms-playwright/chromium_headless_shell-*`，Playwright 临时目录也在仓库内。经 app 自带 CLI wrapper 初始化独立 web profile、link 安装本包，禁用真实模型 provider/自动标题，不发送 prompt。启动 token/cookie 仅在内存用于鉴权，日志/summary 脱敏。
