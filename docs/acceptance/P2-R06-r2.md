## 证据与决策

已查看编排方失败图与摘要：`dist/screenshots/2026-10-21T10-11-30.687Z-40590/failure-v022-avatar-light-editor-ready.png`。编辑器已打开，选择器可见；模态框及遮罩正常遮住背景列表。失败是旧脚本要求“编辑时列表仍可见”，不是编辑器没有打开。

决策：按本次要求拆成每主题两张，共四张。理由：选择器与无遮挡列表属于不同 UI 状态，不应要求同一张图同时满足。

1. `v022-avatar-{light,dark}.png`：locator screenshot 仅截 `[data-avatar-picker]`，包括预览、造型行、颜色行。保留六造型/12 色计数、键盘选择、两行完整可见、真实计算样式对比度检查。测色只包含选择器的 19 个头像（预览 + 6 + 12）。
2. 点击编辑器精确“关闭”，等待 dialog detached，然后截真实 listbox 到 `v022-avatar-list-{light,dark}.png`。逐项检查六个 Bot 的 variant/color 与种子一致、六种造型/六种颜色、整个头像在视口内，且中心 `elementFromPoint` 命中自身后代，证明没有模态框遮挡；单独测列表对比度。
3. 主截图入口期望数量从 avatar 模式的 2 改为 4，亮暗 token 按主题查找比较；其它模式数量不变。成功才发布四个目标文件，失败保留独立 evidence。没有强制点击、延长超时或删除新的对应状态断言。

决策：扩大实际绘制区域并加粗关键特征。理由：原 36px 图块里的 SVG 只有 27.36px，24px 头像内更只有 18.24px，细节继续缩小。

- 造型图块 40px，SVG 占头像 90%，实际 SVG 36px；24px 头像内 SVG 为 21.6px。
- 眼镜改为更宽、相连的粗镜框；喷泉扩大两侧水花与水柱、加大水滴；帽子扩大帽冠和宽帽檐；睡觉加粗闭眼负空间，Zz 线宽从 1.2 增至 2.2。经典轮廓和导航尺寸不变，派生造型仍复用身体路径，仅 currentColor/none。
- 原有双语 title/aria-label 保留，DOM 回归逐个断言六种名称一致、40px 图块和 36px SVG。
