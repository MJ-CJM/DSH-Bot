## 设计取舍与遗留

- 依照 T02 使用 refetch + 轮询，不订阅不会转发的第三方 changed 事件。跨 Client/工具更新按轮询周期可见；当前 unary Remote 无 signal 参数，Abort 只取消本地等待。list/status 没有共同 revision，点击时重新核实仍不等于与 Host 创建原子执行。
- 当前没有现成的全局 Bot 工具目录，隐藏工具采用任务允许的精确名称文本输入。未增加 Host 端点或修改稳定 preset 的事务机制。
- rc.2 Client Loader 不透传 Host Config，因此轮询配置由 Client schema 与页面控件管理，保留于插件存活期、不持久化。构建仅新增精确允许独立 Schemastery/Cosmokit 公开入口，React/Cordis/Zod 继续来自宿主平台。
- CSS modules 的类名映射与字符串来自同一次 CSS 编译，由页面 `<style>` 持有，不依赖宿主自动加载单独 client.css，也不导入内部 UI 组件。未完成真实亮暗视觉验证。
- `uiWorkspace.startSession` 的实际 API 是 `startSession(undefined, {clearPreviousDraft:false, agentPreset})`，返回 void，可复用空白草稿；异步失败由宿主 Workspace notice 呈现。没有当前/最近工作区时该 API 只切回空主视图；须先建立工作区。本轮只验证正确调用参数，不宣称首次无工作区也能完成 Bot 新会话创建。
- 后续由编排方在获准的隔离浏览器/桌面 profile 验证主题、实际工作区聊天导航，以及多 Client 的真实传输刷新。浏览器拒绝后的隔离 Host 已停止，日志保留，没有触碰 `~/.dsh`。

### 取舍与遗留边界

- 选择公开 async Workspace API 是为让 Bot 页面可靠展示异步失败，不通过内部 Workspace 状态或私有 preset seat 实现。同样可能复用空白会话，不承诺每次生成全新持久 session；取消导航不等于撤销 Host 已接受的创建。
- 没有增加 memory Remote，数量显示按本次评审允许延期至 T09；选择保留记忆时严格沿用 Host 的同 ID 关联语义。
- 样式由 React 树持有，不依赖宿主对 factory 阶段 style 的 DOM 扫描；构建缓存按每次 rebuild 清空，既保证同轮映射一致也避免热构建旧 CSS。
- **真实浏览器亮/暗视觉、真实 UI 聊天导航仍为 FAIL（未执行）**：本轮没有重新尝试前轮被安全审批拒绝的浏览器操作。profile 回归证明的是正式 Host/Remote/Agent 行为，不是浏览器渲染；React/jsdom 的失败注入和生命周期测试也不扩大为真实浏览器证据。
