### 设计取舍与遗留

- 被动徽标不追求其他 Client 修改的实时感知；可见性恢复、重连、本 Client 的页面 mutation 和再次挂载可刷新。打开页面仍按配置轮询。
- Host 返回的是当前配置前缀，不是历史删除日志；本命名空间内成功读取却无对应 Bot 的会话显示“已删除”，前缀变更前的历史归属不推测。元数据增加一个廉价 unary 方法，共 14 个 Remote endpoints。
- 旧头像只在返回公共记录时隐藏，原始字段保留。要修改含旧头像的 Bot，应显式选新头像或清空保存；只改其它字段会收到诊断，避免静默清除。base64 白名单不替代图片解码验证，SVG 此轮直接排除。
- 浏览器亮暗视觉验证仍留在 T10；本轮没有把 React/jsdom、主题 token 检查或 Host profile 说成视觉验证。

## 完成内容与设计取舍

- Bot 详情在原编辑器旁增加“记忆”页签。支持内容、类型、标签、来源、创建/更新时间、来源会话导航、词法搜索、分页、编辑、置顶切换、二次确认删除和手工新增。切换页签保留 Bot 设置草稿，但关闭记忆页签释放其 catalog 资源。关闭记忆或完整人设遮蔽记忆段落时显示约定的中英文提示。
- Host 六个记忆端点复用 T06 BotMemoryService/MemoryStore、`dsh_bot` 域和注册表队列，按 botId 隔离，沿用错误码。单一 Zod spec 统一 Host/Client，共 13 endpoints；签名测试覆盖真实方法、参数次序、结果、严格额外字段拒绝及错误码。真实已发布 Gateway 在 fake carrier 下验证点号 namespace 的注册、调用与卸载。
- `remove` 是 rc.2 Gateway namespace 保留方法，所以公开调用采用 `dshBot.memory.delete(botId,id)`；Host 实现名仍为 `remove`。未新增依赖、未改变 peer/dev 锁定规则。
- 新手工记录来源由 Host 强制为 `by:'user'` 与当前时间。T06 去重命中既有记录时保留原来源。save/update 命中 T06 秘密启发式时直接拒绝，UI 显示固定本地化提示，不增加确认绕过，也不回显失败内容。可能误报的凭据样式同样被拒绝；启发式并不能识别所有秘密，既有记录不扫描或迁移。
- Bot 删除确认通过 `count` 显示完整数量，包括超过 200 条的记录。读取失败不伪造 0，显示重试并禁止删除。数量是确认前快照，不锁住其它会话写入；仍按删除该 Bot 全部记忆语义执行。
- 徽标从公开会话 projection 读取当前 preset，再用 `status.presetId` 精确反查 Bot；不拆拼前缀。非 Bot、未知 preset、无映射均不显示。Broken Bot 仍显示，方便进入详情修复。点击通过公开 layout API 打开 Bots 页，一次性请求定位正确 Bot；不随轮询反复打开。
- 刷新复用 T08 catalog 公共实现：首订阅、可见性、connection reset、写后刷新、低频轮询，epoch 和本地 Abort 丢弃迟到响应。轮询默认 5 秒；Client Config.memoryPageSize 默认 50、整数 1–199。分页多读一条判断下一页；列表和总数没有共同 revision，不能称为原子快照。并发更新可能移动分页位置，UI 提供返回首页及说明。
- 来源会话按钮使用公开同步 `uiWorkspace.openSession`；宿主负责异步恢复诊断。本包不发明 URL，不把导航调用通过等同真实会话恢复成功。
