## 已知限制

- **目录不是 Bot 间沙箱。** 默认会话共用 Bots 根，私有 home 用于文件组织和提示；DSH 要求会话 cwd 与所属工作区 path 精确相等。根外写入、提权与审批沿用 DSH。
- **会话配置有代际。** 活跃 Agent 保持原配置；冷恢复使用当前 preset。删除 Bot 不删除历史日志，但可能使对应历史会话无法恢复；同 ID 重建使用新定义。
- **记忆有预算。** 单条最多 2 KiB UTF-8；全部置顶和最近 N 条参与候选，总注入预算默认 4000 UTF-16 字符。`persona.complete=true` 会遮蔽记忆及 home 提示，记忆工具仍按开关/deny 设置工作。秘密检测是启发式，存在误报和漏报。
- **刷新与分页不是事务快照。** 前台共享 watch 与 5–30 秒退避轮询；失焦/隐藏暂停周期读取与流。Bot/activity 变更发 watch；跨 Client 或模型引发的记忆变更依靠轮询/重新聚焦，本 Client 成功写入立即读回。并发写可能移动游标分页位置。
- **原生 UI 有条件。** 空白会话不挂头部 utilities；原生行鲸鱼会给状态点或后续 slot 贡献让位。右侧 tab 和主页面提供原生会话导航，不在插件内嵌整套聊天界面。
- **兼容边界。** 当前运行只验证 DSH 0.2.1-rc.2/macOS；兼容范围声明不是对所有后续版本或 Windows 的实测承诺。P2 routine/delegate、P3 连接器与通知、P4 Bot 间协作不在本期验收范围。
