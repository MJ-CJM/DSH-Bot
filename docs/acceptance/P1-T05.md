## 设计取舍与遗留

运行时模板按 T02 修订执行，因此未新增生产 `templates/*.rows.yml` 或 `scripts/sync-templates.mjs`。standard 编辑已有 provider，minimal 补 provider；不叠加同名 provider，也不替 minimal 添加其它标准工具。Bot extraDirs 按显式配置共享；默认项目/用户技能根继续遵循宿主模板设置，Bot 私有目录不加入全局根。

`composeBotPreset(bot, ctx)` 可读取 Host registry Config，内部启动/测试也可显式传第三参数。Bot 行只携带 botId；注册表在激活期间提供候选快照，避免 Remote 队列重入死锁。活跃 Agent 保留原代际的 persona/deny；失败回滚恢复原策略。目录准备错误不会注销现有 preset；删除和失败回滚保留技能内容，复制只复制 Bot 配置，不复制技能文件。

Bot model 是初始默认值，历史请求和显式会话选择优先，不修改共享默认。最初的固定覆盖方案会与 Host 切模提示冲突，已移除。模型路由和提示词变量已实测，但未发送模型请求，不能声称模型回复、工具循环或冷恢复通过。

Remote Host 契约由手工 `ctx.effect` 注册单一拥有，公开导出从 `dsh-bot/typert` 改为 `dsh-bot/host-contract`；已有调用者需同步路径。Client `/remote` 与业务wire端点保持不变。

未知/同层/保留工具名不能被 DSH restrict 隐藏，会在创建 Agent 时失败；preset healthy 不保证任意 deny 都合法。T08 工具选择器应基于实际可继承目录过滤并呈现创建错误。DSH升级需复核运行时模板、模型waterfall和目录发现；技能修改/删除的实时watch传播、真实UI和跨进程恢复不在本轮证据范围内。

### 设计与边界

双 owner 清理和保留旧代际不冲突：Bot更新注销的是声明，DSH保留仍被Agent引用的代际；主动卸载bot-context插件才会释放其所有Agent effect。本轮真实对象为live但idle的Agent，**没有实测进行中流式turn的热更新**。

模型仍是初始默认，显式选择和历史请求优先。可用性校验采用GUI相同的广告目录政策，比core允许任意模型id更严格；未列出的模型明确拒绝。目录查询可能有网络元数据延迟，不能证明凭据/服务回复可用。测试适配器仅提供目录，任何stream都会失败并计数；最终没有stream或真实模型请求。`system-prompt/assemble` 仍是强机制，需要在DSH升级时复查顺序及贡献合并；没有修改私有Controller状态。
