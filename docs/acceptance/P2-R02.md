日期：2026-10-20（America/Los_Angeles）。任务：[R02-native-aggregate](../../tasks/P2/R02-native-aggregate.md)。分支 `phase/p2-reuse`，起始 HEAD `f7889909ef7d054ad471d17ac9471d602d5428b1`。参考源码 HEAD/tag `dsh-v0.2.1-rc.2` 同为 `687f282e8625c6b8d11ff58211a90524be2e4317`，仅只读。保留既有未跟踪 `.codex/`、`scripts/p2-e2e`；未提交、推送、修改全局 DSH 或桌面应用。未使用真实模型密钥。

## 实现与决策

- 决策：使用原生 catalog/history/update/delete 和 changed 事件，本包只持久化 Bot 创建身份与原生 task/session 的 sidecar。理由：原生已提供规则、存储、投递、冲突检查和历史，不复制调度引擎。
- 决策：存量任务仅凭本包 live 绑定或可靠冷会话 header 归属；会话早于当前 Bot 创建、同 ID 重建、无明确证据时不猜测。理由：标题、名称或 prefix 无法证明身份。未归属任务仍在原生页，不删除。
- 决策：“立即运行”保留既有执行器，使用显式 UI 确认完整指令、approved=true、内容/身份比对与 operationId 幂等。理由：原生定时没有一次新会话执行接口；直接确认是用户 Remote 操作的审批，执行内工具继续受 DSH 审批约束。
- 决策：旧 0.2.0 任务不自动迁移，只显示停用列表并逐条确认删除。理由：目标会话需新建、every 会重锚，暂停/skip/补跑不能等价迁移。坏行跳过，坏文件保留且不阻止启动；有效孤立旧任务仍可从总览删除，详情只显示匹配 Bot 生日的旧任务；旧 runs/control 不恢复、不写入。回退到旧版可能再次启动保留的旧任务。
- 决策：保留 bot_delegate 的现有审批/执行器/reporter，去掉 Dispatcher 依赖。理由：原生委派替换属于后续任务；R02 不把删除调度器扩大为重写委派。
- 决策：清理 build 的生成目录再编译。理由：tsc 不会删除被移除源码对应的旧 JS，不能将旧 Dispatcher/锁夹带进下一次打包。
- 决策：宿主 schedule 禁用时继续支持 P1 与旧任务停用列表；只显示原生服务不可用，不强制改变宿主配置。
