## 决策、限制与建议

1. 决策：群根沿用 U01 已通过的 owned handle + 独立 guard，无需退回普通根。理由：本轮真实所有权、旁路、贡献卸载与冷恢复仍通过。guard 归 retained preset/Agent 代际，群列表停止后不撤掉 Controller 根上的保护。
2. 决策：取消、超时及卸载同时 abort **并立即启动 native activation.dispose**，再等队列/结果。理由：实际 stall 复现了仅 abort 后等待 result 的停滞；补了“只有 disposer 才 settle result”的回归测试。
3. 决策：只增 `dsh_bot_groups` v1 的 groups/members/turns/deliveries/read_state；正文、完整回文 ContentBlock、标题与 child 生命周期仍属原生。理由：不复制模型循环/会话库。群 renderer/context 当前只呈现文字；非文字原样保留原生日志，UI 提示查看 child，不能声称图片已在群页呈现。
4. 决策：保存原生 rename 返回的规范标题，使用公开 `normalizeSessionTitle` 预检、命名期间抑制监听。理由：原生控制字符/空白/字节规范可能改变输入，避免标题修复循环。新增 session-title runtime peer；default-model 只有 type import，精确 dev 无新增 peer。
5. 决策：遇到 Controller 所有权冲突保留只读日志、禁用路由，不取得/销毁裸 Agent。创建/多表写失败保留 recovery_needed 与 Session，不自动删除或重放外部副作用；当前无自动“修复不明创建”按钮。
6. 轮流选择在**准入时**固定；排队时不提前推进指针。Bot revision 变化拒绝原排队 delivery，成员文本 @ 不产生新任务。需要重试时重新发送，产生新可见 operationId；用户应先核对 child，避免重复工具副作用。
7. 没有跨 Host JSON 写协调/跨表事务/exactly-once 保证。群成员使用 Bot 的记忆快照、skills/home、连接器及原生权限；只不复制私聊 transcript，不声称私人信息或文件隔离。
8. 建议在允许浏览器启动的任务沙箱复跑同一 runtime 脚本，再按 §13 补 G01–G03 操作与截图；在 U13 补原生 ask 拒绝和真实强杀恢复窗口。未绕过沙箱或请求扩大权限。
