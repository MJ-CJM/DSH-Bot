日期：2026-10-19。基线分支 `phase/p1`，起始 HEAD `ce2bdfcdcb3f9ab90b8ac5ff8b080b048f732439`，起始工作树干净。参考源码锁定 `dsh-v0.2.1-rc.2` / `687f282e8625c6b8d11ff58211a90524be2e4317`，只读。正式代码和测试只在 `packages/dsh-bot/`；另外更新 API 记录、本文和根 lockfile。没有 commit/push、全局安装、修改桌面应用或真实 `~/.dsh`，没有真实模型请求。

## 实现与设计取舍

- Host 新增 `dshBot/ensureHome(botId) → {path}`，从公开 `@deepseek-ai/dsh-home-paths` 根出口解析 DSH home；路径固定为 `<home>/dsh-bot/bots/<id>/home`，不跟随自定义 skills `dataDir`。串行 registry 队列保证并发幂等，创建和重新使用时确保 POSIX mode 0700。
- 路径除 Bot ID schema 外，还做逐层 lstat/realpath 和根包含检查。受管组件不接受 symlink。home 同级 `.home-owner.json`（0600）保存 owner/version/botId/path/dev/ino；不接管既有未标记目录，不删除被替换 inode。home 内的子 symlink 删除不跟随目标。它是防误删措施，不是对抗同 OS 用户恶意并发改名的内核隔离机制。
- 复用已有 `defaultCwd` 字段和 `null` 清除协议。浏览器校验绝对路径语法，Host 校验本平台绝对路径且目录存在；允许用户选择指向现有目录的 symlink。用户目录只验证，不 mkdir/chmod/rm。编辑器显示路径、可输入、调用公开 pickDirectory、恢复默认和原生权限说明；新 Bot 保存前尚无 Host 身份，显示保存后分配提示。
- 三个主入口（Bots 页、Bot 会话弹层 +、右栏无历史 Bot）重新读取 Bot 与 Host status，优先 defaultCwd，否则 ensureHome，然后 `ctx.sessions.create({cwd,agentPreset})`，成功后 `openSession`。不读取工作区数量作为前置。加载/创建错误内联显示，不导航；取消、导航被取代、卸载后迟到响应不导航。Host 已接受的创建可能留下空白会话，不承诺取消回滚。
- 三个界面更多菜单保留“在工作区中新建…”，复用既有工作区选择与 `openWorkspace(...,{agentPreset})`。稳定 preset id、T08g 标题与刷新机制不变；`home` 只是原生 displayTitle 可能的回退，Bot 列表仍显示真实标题、首条摘要或“新会话”。
- 删除对话框 `deleteHome` 默认不勾选；默认删除只清 Bot/按选择清记忆，保留 home。勾选后只删受管 home，保留 skills 和用户 defaultCwd。先验证归属，再提交 Bot 删除，最后清目录；存储失败保留 home，清理失败返回 `bot/home-cleanup-failed`。Client 读回列表并明确提示 Bot 已删除、目录未完全清理。`bot_manage` 的原审批只涉及记忆，因此仍拒绝 deleteHome 参数。
- 未增权限、审批、沙箱设置或模型文件访问闸门。默认 workspace-write + ask，用户选 full access 时原样沿用。源码确认 fs 读取不受 cwd 边界限制，写入限 cwd/临时目录，提权重试走原生审批；本轮没有把 mock 文本对话当作越界写入/人类审批弹窗实测。
- 未找到按 Bot 隐藏原生会话的公开过滤 API，保留单一“未分组”桶，不创建每 Bot workspace。源码表明正常冷恢复不重做 workspace bootstrap（本轮运行验证冷恢复 cwd 与活动，未重复读取冷恢复的 workspace membership）；若清空 workspace 域却保留旧日志，DSH 首次迁移会按历史 cwd 建组（原生行为）。测试和截图脚本现在同时隔离 storage root 与 session log root。

## 遗留问题

- 六张真实宿主截图待执行；本轮未做真实目录选择器 GUI、原生越界写入审批、Windows mode/ACL 验证。
- Bot store 与文件系统没有跨资源事务。归属标记写入失败、清理中断或目录被外部替换时拒绝自动接管，可能留下需人工检查的目录/标记。不要直接删用户文件来“修复”；默认保留和显式失败优先。
- 用户保存 defaultCwd 后仍可自行移走目录。校验是保存时的状态，不是锁定目录或访问授权；后续会话与文件操作错误继续由 DSH 处理。
