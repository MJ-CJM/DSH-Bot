## 失败迭代与决策

- 初次 E2E（目录 `1792553800928-76464`）**FAIL**：探针误用不存在的 Agent.prompt。修为公开 SessionController.prompt；产品没有该调用。
- 第二次 E2E（目录 `1792553838627-77567`）**FAIL**：原生时间/运行环境消息追加在人工输入后，初版“最后任意 user/message”门禁误判为后台通知，未启动子代理。修为跳过原生 agent-instructions/runtime-context/time-context/tmux-context 环境消息，同时不清除先前通知屏障；单元回归和第三次真实 E2E 通过。失败证据均保留。
- 决策：采用原生在线父回报，删除本包持久 reporter。理由：普通委派完全由原生执行/回报，无须并行 outbox。父对象被卸载/替换后不补发；不承诺旧摘要脱敏/长度上限。
- 决策：不保留“需要子任务交互审批”的隐藏执行模式。理由：原生 child 的 never 策略会拒绝 ask，不得为复用而提权；需要交互审批时使用普通 Bot 会话。入口审批仅授权发起委派。
- 决策：仅保留 manual 的普通会话 RunExecutor。理由：它服务已批准的显式立即运行，原生委派不调用它。
