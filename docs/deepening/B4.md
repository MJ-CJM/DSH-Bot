## 实现细节

预览只接受 memoryId 和范围选择；targets、epoch、收据状态不能由 Client/模型提供。
已知重复限定同一读取域，派生依赖做传递闭包；逻辑记忆的全部旧版本一同遗忘。
预览 token 只由服务端持有并限量，提交前在内核队列重新核对 revision 与依赖 stamp。
预览不展示正文，也不把正文或可反推 hash 写入阶段收据。统计仅覆盖已观测数据。

未知闭包采用明确提示的保守范围：受影响已知会话在系统头部之后的全部模型可见历史，
以及全部受管图谱。用户可以取消，或只停用并保持屏障。
提交后不自动扩大批准的 session/target 清单；无法证明闭包完整就维持 blocked。
历史清理 cancel→whenIdle→runMaintenance，按 surface 顺序替换完整工具配对，
sourceEventSeqs 列全；不调用 compactNow、摘要模型、空闲 system append 或新建会话。

forget_jobs 持久 intent 早于 forget op；只有 op 是停用线性化点。
恢复会完成同一 opId 的未决意图；payload、旧投影、旧迁移 ID 附件随墓碑清理。
最终 verified 收据先落盘、barrier 后释放；该窗口故障的 UNIT 冷恢复保持同一收据。
工具路径旧 memory_forget 同样保留停用意图，返回文案明确强遗忘待完成。

ReferenceMemory 在自己的 control 队列排空复制/调用、关闭 MCP 子进程后，
扫描所有受管代际文件（含 orphan stage），拒绝符号链接/异常目录，删除图谱和 copies 完整快照。
绑定撤销 import 指针、切回 internal；不可达/失败保留屏障，未声称重挂载后的模型读取通过。
用户外部备份、原始事件、已经发送的数据均明确排除。

根检测只 lstat AGENTS.md、CLAUDE.md 及两个 local overlay；没有打开指令正文或删除文件。
独立 required literal context 对所有 Bot（含 memory-disabled）声明根指令的原生加载边界。
普通使用只警告；强遗忘不能验证根来源时仍阻断。自定义原生候选和全读取出口尚未审计。
UI 使用 locale/alias 样式和稳定组件；没有导入 DSH 私有 Client 组件。
