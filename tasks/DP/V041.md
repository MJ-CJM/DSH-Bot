# V041（gpt-6.1-sol / high）：两项修复 + 0.4.1（基于 phase/deepening HEAD 33e7acf）

## 1. Bots 列表单击不应进入对话（用户反馈：“在这里点击，怎么就直接跳到对话去了？”）
packages/dsh-bot/src/client/components/BotList.tsx 约 91 行 onClick 同时调用 onSelect 和 onActivate。改为：
- 单击只选中（右侧显示详情面板）；打开对话只能经详情面板「打开对话」按钮、Enter/Space、或双击。
- 紧凑/窄屏布局：单击显示详情视图（setShowDetail），不打开对话。
- 保持键盘 a11y（listbox/option、aria-selected、方向键、Enter/Space 激活、焦点管理），中英一致。
- 更新单测/DOM 测试与浏览器 e2e：断言单击后未打开对话、详情面板可见；按钮/Enter/双击才打开；窄屏同理。
- 增加 e2e 套件 bots-list（中英×亮暗×宽窄截图：单击后详情态），沿用 sidebar 展开逻辑。

## 2. 运行中原地升级（0.3.2 运行时装 0.4.0 报 `The requested module ./schema.js does not provide an export named memoryFields`）
原因：宿主进程 ESM 缓存保留旧 schema.js。
- 新增发布测试：在一个存活的 Host 进程中先装旧版并激活，再原地安装新 tgz（不重启），复现该类错误，并验证新行为。
- 插件激活时检测模块版本不一致/陈旧（如：入口与各模块导出版本戳、或入口对子模块使用带版本查询串的动态 import 并比对 VERSION 常量；
  或捕获链接期 SyntaxError），给出清晰的中英提示「请完全退出并重新打开 DSH」/“Fully quit and reopen DSH”，不显示原始 SyntaxError，不写入/迁移数据。
- 若静态 import 的链接期错误无法在插件内拦截，说明原因与实际可达到的范围（例如入口改为小型引导模块 + 动态 import），如实记录，不伪造通过。
