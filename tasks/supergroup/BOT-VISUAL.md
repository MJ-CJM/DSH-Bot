# Bot 聊天界面重设计实施

日期：2026-11-12。用户已批准 [视觉稿](../../docs/design/supergroup/visual-review-v2/README.md) 全部实施，并授权部署到本地独立 DSH 审批服务；日常桌面版和数据保持不动。沿用 `codex/supergroup-p0`，保留现有工作区，不提交、推送或发布。

## 范围

1. 联系人列表、真实头像、搜索、置顶/更多菜单、最近完成群、单一设置入口。
2. 原生聊天空态占位和底部输入、合理阅读宽度，保留草稿、模型、权限与审批。
3. 轻量协作卡、真实成员动态、原 Bot 交付和返回入口。
4. 默认收起的详情/资料/成员；宽屏并排、中等窗口覆盖、窄屏单页返回。
5. 中英与亮暗主题、同名对象、连接/未知发送状态、停止时陈旧状态保护。

## 隔离与验收

- 先在独立验证 profile 安装冻结包；实际 HTTP factory 核对五个模块来源，不改写响应。
- 空态→首条消息、长回复、多行输入、原生审批、模型/权限、详情阅读位置和草稿须在真实 Browser 测量验证。原型的 52 项检查不作产品证据。
- 完整协作流程与双窗口/冷重启回归，使用明确标记的本地合成模型，不使用真实 API key。
- 最终仅更新 `.dsh-dev/bot-mode-approval/` 服务。升级前备份其已有数据；现有桌面五个关键文件前后核对，原审批环境 Bot/记忆/主绑定须保留。
- 完整 `scripts/pnpm check`、格式、链接、实际源构建→冻结包→运行安装审计。

已完成实现并部署最终 E 到独立审批服务，见[交付与验收报告](../../docs/verification/bot-mode-visual-delivery.md)。1702 项仓库测试、776 项真实视觉检查、65 项协作流程、25 项冷重启、33 项同包重连和 5 组 Host 输入检查均通过。原生窄屏轨道、输入提示文案、最近 200 条之外加入动态，以及真实模型／完整桌面未运行范围在报告中分别说明。
