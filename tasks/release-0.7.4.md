# 0.7.4 发布

用户于 2026-11-24 要求发布当前已验收版本，并保留现有多轮群聊行为。发版分支为 `codex/release-0.7.4`，基于 main `3c6cc22d3939fcba284199d524c782d58a941524`。公开基线为 `dsh-botgroup@0.7.3`。原工作区改动保留。

## 范围

- 交付已实现的群成员统一管理、单次移出确认、新增历史授权、完整停用名单、成员修改收据与并发保护、旧受众授权失效。
- 保留当前 Bot、群聊、私聊及私有记忆的权限边界；不调整多轮交流策略、路由和模型预算。
- 同步版本、双语发布说明、更新记录及 README。README 使用本版本说明，公开下载版本以实际 Release/npm dist-tag 为准，保留社区入口。
- 复用此前已验收业务实现；版本更新后冻结新包并绑定新 SHA 复验，发布时不重新构建。

## 流程与门槛

1. 核对公开 npm/GitHub 版本及 main，确认准确功能差异。
2. 完成源码检查、冻结 0.7.4 包和发布说明；核对与已验收本地候选的版本及元数据差异。
3. 对同一冻结包运行适用的隔离 Host、升级、冷启动与数据保留检查，分别记录执行和未运行范围。
4. 编排方提交并推送独立发版分支、提 PR 到 main，交由用户合并；核对当前 PR 与合并后的 CI。
5. 合并后用同一份已复验原包和发布说明发布 npm/GitHub，不在上传前重新构建。
6. 核对 npm `latest`、GitHub `latest`、版本名和固定名下载包的校验和；分别记录社区入口状态。
