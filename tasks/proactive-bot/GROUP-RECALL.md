# 群经历回到个人 Bot

用户已批准全部实现。沿用 0.6.6，在当前分支开发；本任务不部署日常桌面、提交或公开发布。

## 范围与交付行为

1. **P0 原生核实**：使用锁定 rc.2 公开 SessionQuery、SessionPersistence 和工具服务验证准确会话范围、当前 surface、冷读取、中文检索、取消与资源边界。
2. **P1 个人召回**：个人主会话提供 `bot_group_recall`，从现有群、轮次和真实执行收据导出本 Bot 参与记录，按需读取原问题、本人回答与当时已获准的上下文。返回群名及准确消息引用。没有已保存记忆的旧 Bot 也可召回；不补造任务或长期记忆。
3. **P2 现有入口**：在 Bot 记忆页展示最近参与、搜索、分页、查看原文及“记住结论”；群内“单聊追问”携带所选成员的准确工作引用。草稿需要用户发送，复用现有长期记忆保存工具。

复用原记忆开关、群成员身份、Bot/群代际、原生会话、Remote、工具生命周期、记忆域与遗忘屏障。新域表只记录已读来源的身份和摘要哈希，用于后续对话重新核验；不保存群正文、不做群记录自动复制、不加后台模型、不另建搜索数据库。

## 验收门槛

- 真实参加自然/顺序群执行的成员能找到自己的工作；仅加入、仅收到 Inbox、未开始或错误成员代际不能据此认领参与。
- 同工作区其他群、私人子会话和其他 Bot 回答不进入本 Bot 召回。当前 surface 已替换的内容不能靠原日志重新读出。
- 冷启动查询不创建额外 Agent，不调用模型，不恢复工作者；默认未启用原生全文索引仍能查询中文片段。
- 关闭记忆后，保留主会话的召回工具及提示同步消失；开启后恢复；普通聊天及其他 Bot 不受误拦截。
- 来源变化、退群、重加、遗忘和分支继承均在模型请求前重新核验。验证失败不得继续把旧群正文送给模型。
- 记忆页与私聊入口使用真实 Remote，操作前复核来源；原文定位准确，已有输入不被覆盖，无自动发送。
- 完整源码检查、真实双宿主同包验收，以及明暗/中英/窄窗口的实际 Web 验证通过。真实模型回答质量由用户后续验收，不能用合成 provider 代替。
