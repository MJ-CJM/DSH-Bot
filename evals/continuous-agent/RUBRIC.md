# 冻结的人工审阅与评分规则 v1

整理审阅侧只能看到截止前授权来源、B 快照和一个 C 候选，不可查看任务问题、Gold、模型名称或回答。按来源等价、时间正确、保留不确定性、权限不扩大、来源未撤销五项逐条批准或拒绝；不可重写、补答案或生成多个候选择优。记录审阅秒数、决定和理由。拒绝后继续使用原 B 副本作 C 回答，仍计入整理成本。

回答评分侧独立于候选审阅侧，只拿随机盲编号、回答、冻结 Gold 和授权来源。自动 `scoreAnswer` 核对合成事实、禁止信息、动作和 canary；人工按任务是否完成、依据是否充分、时间是否正确及是否引入新推断逐项通过或拒绝。评分有分歧时记录理由并复核，不因看到臂身份改变规则。

发布候选/提示/参数/语料哈希、模型预算和 120 槽位清单后，最终批次只登记一次；所有失败保留分母。未经模型、数据和费用授权，本目录不会主动调用提供商。`runBatch` 的适配器必须使用隔离 Host、真实产品检索/整理与独立会话，并保存请求和成本收据。未附实际收据不能标记真实质量通过。
