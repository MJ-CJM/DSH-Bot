# 持续任务与记忆评估

质量和机制分开。`data/manifest.json` 冻结 24 个合成质量场景（8/8/8）；Gold 独立文件只交评分侧。普通测试只验证最终文件哈希和结构，不读取其事实来调优。`freeze.mjs` 拒绝覆盖已冻结实验。不得将 Gold 目录交给 Agent、索引或记忆整理。

`protocol.ts` 定义 120 个固定回答槽位，保留失败、unknown 和未启动分母；校验跨臂会话/存储、来源权限和时间截点、模型及基础上下文一致性。成本按 N=1 完整计入整理费用，缺用量不填零。`runner.ts` 以隔离适配器运行完整批次，准备失败不会删题或自动重试。

`tests/continuous-agent/evaluation.spec.ts` 是独立的 24 机制用例，调用当前内核写入与真实 BM25 检索。其 C 在接入实际整理前明确使用 fixture，不能用于质量收益声明。单元计分通过不等于 Host/模型回答验证。

真实模型批次：FAIL（NOT_RUN，尚未取得具体模型、资料范围和费用预算授权）。首次最终批次须登记候选实现/提示/参数/语料哈希与完整槽位，锁定后只运行一次；修改候选必须新建实验。费用、初始化、整理、人工审阅及盲评按设计分别保存。
